## 1. 架構總覽

```
push_manager.py
├── BaseChannel           抽象基底類別（定義推送介面）
│   ├── send_text()       發送純文字
│   ├── send_video()      發送影片
│   ├── send_image()      發送圖片
│   └── send_document()   發送文件
│
├── TelegramChannel       電報通道實現
├── PushManager           統一入口（多通道並行）
└── CHANNEL_REGISTRY      通道登記表（擴展只需加一行）
```

### 支援內容類型

| 類型 | 方法 | 格式 | 上限 |
|---|---|---|---|
| 純文字 | `send_text` | 任意文字 | 4096 字元 |
| 影片 | `send_video` | `.mp4 .mkv .webm .avi .mov .flv` | 50 MB |
| 圖片 | `send_image` | `.jpg .jpeg .png .gif .webp .bmp` | 10 MB |
| 文件 | `send_document` | 任意格式 | 50 MB |

> **智慧發送**：媒體根據副檔名自動選擇 `sendVideo` / `sendPhoto` / `sendDocument`  
> **自動降級**：影片 > 50 MB 或圖片 > 10 MB 時自動改用 `sendDocument`  
> **Caption**：圖/影/文件可附加說明文字，上限 1024 字元

## 2. 環境配置（.env）

在 `.claude/skills/tdm/.env` 中配置：

```env
# ============================================================
# 通用推送模組配置
# ============================================================

# 是否啟用推送功能 (true/false)
PUSH_ENABLED=true

# 預設推送通道，逗號分隔（目前支援: tg, telegram）
PUSH_DEFAULT_TARGET=tg

# Telegram Bot Token（從 @BotFather 取得）
TG_TOKEN=************:****AAEN6lmrIE****

# Telegram Chat ID（接收方）
TG_CHATID=33333333**
```

### TG_CHATID 格式說明

| 接收方 | 格式 | 範例 | 如何取得 |
|---|---|---|---|
| 個人聊天 | 9 位數字 | `550497384` | 私聊機器人後訪問 `https://api.telegram.org/bot<TOKEN>/getUpdates` |
| 群組 | `-` 開頭 | `-4001234567` | 將機器人加入群組，發一條訊息後訪問上方 API |
| 頻道 | `-100` 開頭 | `-1001234567890` | 將機器人設為頻道管理員後訪問上方 API |

### 取得 Chat ID 的快速方法

1. 在 Telegram 中對你的機器人發送任意訊息
2. 瀏覽器訪問：`https://api.telegram.org/bot<你的TOKEN>/getUpdates`
3. 在回傳 JSON 中找到 `"chat":{"id":550497384}` → 這就是你的 Chat ID

## 4. Python API（程式導入）

```python
from push_manager import PushManager, push_text, push_video, push_image, push_media

# ── 方式一：便捷函數（一行推送）──
push_text("下載完成：世界盃16強.mp4")
push_video("video.mp4", "新聞影片")
push_image("photo.jpg", "截圖")
push_media("file.pdf", "報表")          # 自動判斷類型

# 指定通道
push_text("通知", targets="tg")
push_video("video.mp4", "標題", targets="tg,wx")

# ── 方式二：PushManager 實例（更靈活）──
mgr = PushManager("tg")                 # 可傳 "tg,wx,discord"
mgr.push_text("多通道通知")
mgr.push_video("video.mp4", "標題")
mgr.push_media("photo.jpg")             # 自動判斷類型

# 檢查可用性
print(mgr.available)                    # 至少一個通道已配置？
for ch in mgr.channels:
    print(f"{ch.name}: {ch.is_configured()}")

# ── 方式三：取得詳細結果 ──
results = mgr.push_video("video.mp4", "測試")
for channel_name, result in results.items():
    print(f"{channel_name}: {'OK' if result.success else 'FAIL'}")
    print(f"  {result.message or result.error}")
```

### 整合到 TDM 下載流程

```python
from tdm_core import download_video, push_to_channels

# 下載 + 推送
result = download_video(
    news_id="1217791",
    push_enabled=True,          # 啟用推送
    push_targets="tg",          # 目標通道
)
# result["push_results"] → {"telegram": {"success": True, "message": "..."}}

# 獨立推送已下載的檔案
push_to_channels("video.mp4", "新聞標題", "tg")
```

## 6. 錯誤處理

| 情境 | 行為 |
|---|---|
| `python-telegram-bot` 未安裝 | import 時提示安裝，通道標記為不可用 |
| `TG_TOKEN` 或 `TG_CHATID` 未配置 | `is_configured()` 回傳 False，推送時回傳錯誤訊息 |
| 檔案不存在 | 回傳 `PushResult(success=False, error="檔案不存在: ...")` |
| 檔案超過大小限制 | 自動降級為 `sendDocument`；若文件也超限則回傳錯誤 |
| 網路超時 / API 錯誤 | 回傳 `PushResult(success=False, error="...")` |
| `PUSH_ENABLED=false` | 所有推送跳過（CLI 模式下直接 exit 0） |
| 指定未知通道 | 跳過該通道並在 console 輸出警告，不影響其他通道 |
