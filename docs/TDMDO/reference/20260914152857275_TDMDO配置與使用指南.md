## 1. 系統架構概覽

TDMDO 由三個核心層次構成：

```text

│                       用戶交互與接口層                         │
├───────────────────────────────┬─────────────────────────────┤
│      Web 網頁端服務            │      Skills / CLI 工具      │
│      (app/tdm_web.py)         │  (tdm_tool.py / push_mgr)   │
│  - 瀏覽器響應式 UI             │  - 自然語言 Agent 技能喚起   │
│  - 遠端 HTTP API 伺服器        │  - 本地終端指令操作          │
│  - 內建密碼 Cookie 認證       │  - 支援連接遠端 Web Server   │
└───────────────┬───────────────┴──────────────┬──────────────┘
                │                              │
                ▼                              ▼
┌─────────────────────────────────────────────────────────────┐
│                       核心邏輯與持久層                       │
│                     (scripts/tdm_core.py)                   │
│  - TDM 官方 API 請求封裝（免登入、免 JS 渲染）               │

│  - WebDAV / Telegram 自動推播通道                           │
└─────────────────────────────────────────────────────────────┘
```

## 2. 環境變數 (.env) 載入優先順序

為確保在多個 Agent（Claude Code、DSH、Codex）與獨立 Web 服務之間保持行為一致，系統對環境變數載入進行了全域統一，採用**非覆蓋式（setdefault）鏈式載入**。

### 載入順序（由高至低，前者優先）

| 優先級 | 載入來源 | 說明 |
|:---:|---|---|
| **1 (最高)** | **系統環境變數** (`os.environ`) | 終端 Shell `export`/`set` 或命令列臨時傳入的環境變數，永遠最高，不被任何檔案覆蓋。 |
| **2** | **專案根目錄 `.env`** (`<project_root>/.env`) | **最推薦的配置方式**。在此集中管理全專案共用的路徑、密碼與推播憑據。 |
| **3** | **Skill 目錄 `.env`** (`.claude/skills/tdm/.env`) | 歷史向下相容。若根目錄未設定某些參數，則回退讀取 Skill 專屬配置。 |
| **4** | **當前工作目錄 `.env`** (`Path.cwd()/.env`) | 防禦性保底（例如在其他子目錄中執行腳本時）。 |
| **5 (最低)** | **程式碼內建預設值** (Default Fallback) | 程式內預設參數（如下載預設進 `.claude/skills/tdm/downloads`）。 |

> **配置建議**：
> 1. 直接在專案根目錄複製一份 `.env`：`cp .env.example .env`。
> 2. 在根目錄的 `.env` 中設定好 `TDM_DOWNLOAD_DIR`、`WEBDAV_*`、`TG_*` 等變數。
> 3. Web 端與所有 Agent 即可自動共享同一份配置，無須在各子目錄間手動同步。

## 3. 下載目錄與檔案路徑配置 (`TDM_DOWNLOAD_DIR`)

`TDM_DOWNLOAD_DIR` 控制所有下載的新聞影片、裁剪片段的落盤目錄。

### 路徑解析機制

1. **絕對路徑**：
   - 範例：`TDM_DOWNLOAD_DIR=D:/Videos/TDM` 或 `TDM_DOWNLOAD_DIR=/var/media/tdm`
   - 行為：直接解析並落盤至該實體路徑。
2. **相對路徑**：
   - 範例：`TDM_DOWNLOAD_DIR=downloads`
   - 行為：**固定相對於專案根目錄解析**（即 `<專案根>/downloads`）。無論執行命令時當前終端在哪個子目錄（例如在 `app/` 或 `.claude/skills/tdm/scripts/`），皆精確定位到專案根目錄的子資料夾，不會在各處留下零散的資料夾。
3. **未設定（留空或未定義）**：
   - 行為：自動預設為 `<專案根>/.claude/skills/tdm/downloads`。

### Web 端與 Skill 端對下載目錄的處理差異

* **Web 端 (`app/tdm_web.py`) 的安全限制**：
  * Web 服務具有沙盒防護邏輯，**限制所有下載檔案及裁剪產物只能存放在 `TDM_DOWNLOAD_DIR` 內**。
  * 禁止客戶端指定任意目錄（防止目錄遍歷攻擊），頁面上的刪除、播放、下載等功能均只對 `DOWNLOAD_DIR` 直屬檔案生效。
* **Skill / CLI 端 (`tdm_tool.py`) 的靈活性**：
  * 預設情況下，`download` 與 `trim` 自動儲存至 `TDM_DOWNLOAD_DIR`。
  * 同時 CLI 支援手動傳入 `--output` 參數。若手動傳入絕對路徑或另行指定檔名，CLI 工具尊重用戶命令列選項。

## 4. Web 網頁端使用說明 (`app/tdm_web.py`)

Web 端是基於 Flask 的現代化輕量服務，集「視覺化操作介面」與「遠端算力伺服器」於一身。

### 4.1 啟動方式

```bash
# 1. 僅本機存取（預設埠 8080）
python app/tdm_web.py --host 127.0.0.1 --port 8080

# 2. 開放內網/區域網路存取（供其他機器或輕量客戶端呼叫）
python app/tdm_web.py --host 0.0.0.0 --port 8080
```

### 4.2 密碼保護機制 (Auth)

* 在 `.env` 中設定：
  ```env
  WEB_AUTH_ENABLED=true
  WEB_AUTH_PASSWORDS=mypassword123,admin888
  ```
* **效果**：
  * 訪問網頁會彈出認證遮罩層，輸入密碼通過後寫入 HTTP-only Cookie（有效期限 30 天）。
  * 後端對 `/api/` 路由同步進行嚴格保護，未登入的 HTTP 請求直接回傳 `401 Unauthorized`。

### 4.3 介面核心功能

1. **即時新聞列表**：自動請求 TDM 官網 API，展示最新新聞標題、時間、縮圖、分類，並支援分類篩選（本地、要聞、體育、特稿）。
2. **影片線上搜尋與播放**：支援全文關鍵字搜尋新聞或短視頻，點擊即可透過內建 HLS.js 播放器即時預覽串流。
3. **線上精確裁剪與下載**：支援在播放過程中設定起點與終點（支援毫秒/小數秒），後端自動調用 ffmpeg 擷取並落盤至 `DOWNLOAD_DIR`。
4. **影片庫與推播管理**：管理下載目錄內的影片，提供一鍵推播至 Telegram 或 WebDAV。

## 5. Skills / CLI 使用說明 (`tdm_tool.py`)

Skill 支援 **本地執行模式** 與 **遠端調用模式** 兩種運作形態。

### 5.1 本地模式（本機具備 Python + ffmpeg）

當前環境已安裝 `requests`、`ffmpeg` 時，直接運行：

```bash
# 查詢最新影片新聞（顯示 10 篇）
python .claude/skills/tdm/scripts/tdm_tool.py news --video-only --limit 10

# 搜尋特定主題新聞
python .claude/skills/tdm/scripts/tdm_tool.py search "澳門 科技"

# 根據新聞 ID 或網址下載完整影片
python .claude/skills/tdm/scripts/tdm_tool.py download --id 1238610
python .claude/skills/tdm/scripts/tdm_tool.py download --url "https://www.tdm.com.mo/zh-hant/news-detail/1238610"

# 下載時直接指定裁剪範圍（--cut 起點秒數,持續時間）
python .claude/skills/tdm/scripts/tdm_tool.py download --id 1238610 --cut 00:00:20,00:00:30

# 對現有影片進行後續精確裁剪（支援毫秒）
python .claude/skills/tdm/scripts/tdm_tool.py trim --input video.mp4 --start 10.500 --end 35.200 --output clip.mp4

# 推送純文字、影片或檔案至 Telegram
python .claude/skills/tdm/scripts/tdm_tool.py push --text "新聞已更新"
python .claude/skills/tdm/scripts/push_manager.py --video clip.mp4 --caption "精選片段"
```

### 5.2 遠端模式（客戶端免裝 ffmpeg / SQLite）

當客戶端是輕量機器、容器或不具備編解碼環境時，只需安裝 `pip install requests`，將計算任務交給 Web 伺服器：

1. **伺服器端**啟動 Web 服務：
   ```bash
   python app/tdm_web.py --host 0.0.0.0 --port 8080
   ```
2. **客戶端**配置 `.env`（或透過命令列）：
   ```env
   TDM_SERVER=http://192.168.1.100:8080
   TDM_SERVER_PASSWORD=mypassword123
   ```
3. 客戶端的所有 CLI 操作將自動轉換為對應的 HTTP API 呼叫，下載與裁剪均在伺服器端完成。

### 5.3 在各 Agent 中觸發

目前三個主流 Agent 均能調用本 Skill：
* **Claude Code (cc)**：原生掃描 `.claude/skills/tdm`。
* **DSH (DeepSeek Harness)**：自動掃描 `.agents/skills/tdm`（透過專案根目錄 Junction 映射）。
* **Codex**：透過 `.agents/skills` 掃描。

**自然語言觸發詞**：
> 「獲取最新 TDM 視頻新聞」、「下載澳廣視新聞 1238610」、「搜索澳門天氣並裁剪前 30 秒」、「推播最新新聞到 Telegram」。

## 6. 完整配置參數一覽表

| 變數名稱 | 適用元件 | 預設值 | 說明與範例 |
|---|:---:|---|---|
| `TDM_DOWNLOAD_DIR` | Web / Skill | `<專案根>/.claude/skills/tdm/downloads` | 影片落盤目錄，支援絕對路徑（如 `D:/Videos`）或相對路徑（如 `downloads`）。 |
| `TDM_DB_PATH` | Web / Skill | `<專案根>/.claude/skills/tdm/scripts/tdm_news.db` | SQLite 資料庫路徑（本地快取與新聞索引）。 |
| `TDM_SERVER` | Skill / CLI | (空，即本地模式) | 遠端伺服器 URL，例如 `http://192.168.1.100:8080`。 |
| `TDM_SERVER_PASSWORD` | Skill / CLI | (空) | 遠端伺服器的存取密碼（對應 `WEB_AUTH_PASSWORDS`）。 |
| `TDM_REMOTE_POLL_TIMEOUT` | Skill / CLI | `600` | 遠端下載輪詢最長等待時間（秒）。 |
| `WEB_AUTH_ENABLED` | Web | `false` | 是否啟用 Web 介面與遠端 API 認證 (`true`/`false`)。 |
| `WEB_AUTH_PASSWORDS` | Web | (空) | 允許登入的密碼清單，多個以逗號隔開。 |
| `WEBDAV_ENABLED` | Web / Skill | `false` | 下載完成後是否自動透過 WebDAV 推送。 |
| `WEBDAV_URL` | Web / Skill | (空) | WebDAV 服務端點，例如 `http://192.168.1.100:5244`。 |
| `WEBDAV_USERNAME` | Web / Skill | (空) | WebDAV 登入帳號。 |
| `WEBDAV_PASSWORD` | Web / Skill | (空) | WebDAV 登入密碼。 |
| `WEBDAV_PATH` | Web / Skill | `/` | WebDAV 目標存放目錄（需確保遠端已建立）。 |
| `PUSH_ENABLED` | Web / Skill | `true` | 是否啟用通用推播通道。 |
| `PUSH_DEFAULT_TARGET` | Web / Skill | `tg` | 預設推播目標（多通道逗號分隔，目前支援 `tg`）。 |
| `TG_TOKEN` | Web / Skill | (空) | Telegram Bot API Token。 |
| `TG_CHATID` | Web / Skill | (空) | Telegram 接收訊息的個人/群組/頻道 ID。 |

## 7. 伺服器遷移檢核清單 (Migration Checklist)

若將專案遷移至全新伺服器，請按以下步驟完成恢復：

1. **依賴環境安裝**：
   - Python ≥ 3.9
   - 系統編解碼工具：`ffmpeg`（確保加入 PATH）
   - Python 依賴包：
     ```bash
     pip install requests flask python-telegram-bot yt-dlp
     ```
2. **複製設定檔與歷史庫**（這兩者在 `.gitignore` 中不會隨 Git 同步）：
   - 從舊機器複製 `.env` 至專案根目錄。
   - （可選）複製 `tdm_news.db` 至指定資料庫位置。
3. **重建 Agent 技能聯接**（非 Windows 環境或乾淨克隆時）：
   - **Windows (PowerShell)**：
     ```powershell
     New-Item -ItemType Junction -Path ".agents\skills\tdm" -Target ".claude\skills\tdm"
     ```
   - **Linux / macOS (Bash)**：
     ```bash
     mkdir -p .agents/skills
     ln -s ../../.claude/skills/tdm .agents/skills/tdm
     ```
4. **驗證指令**：
   ```bash
   python .claude/skills/tdm/scripts/tdm_tool.py news --limit 3
   ```
