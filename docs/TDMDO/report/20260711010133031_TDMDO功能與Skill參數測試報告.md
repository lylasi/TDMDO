## 五、Runtime Verification 證據

### Web 認證

1. 未登入開啟 `/`：HTTP 401，頁面標題 `TDMDO — 登入`，只顯示密碼輸入框與解鎖按鈕。
2. 未登入請求 `/api/videos`：HTTP 401 JSON。
3. 數字 password：HTTP 400。
4. 正確密碼登入：HTTP 200；瀏覽器進入完整 TDMDO 主頁。
5. 登入後 `/api/videos`：HTTP 200。
6. `page=nope`、`limit=x`：HTTP 400。

### 真實裁剪與首次入庫

- 以 ffmpeg 建立 2 秒、32×32 的本機測試影片。
- 呼叫 `/api/trim`：start `0.25s`、duration `0.50s`、output `clip.mp4`。
- 回應：HTTP 200，`{"ok": true, "filename": "clip.mp4", "push_ok": false}`。
- `/api/videos` 可見 `clip.mp4`，`source_type=cut`。
- 同時提供 end 與 duration：HTTP 400。
- 全新資料庫流程未再出現 `no such table: videos`。

### m3u8

- 經 `/api/news?video_only=1&size=1` 取得影片 ID。
- 經 `/api/query-video` 取得 m3u8。
- 實際結尾為 `/playelist.m3u8`，未出現 `playelist.m3u8list.m3u8`。

### 遠端 CLI

實際命令均經 CLI 入口執行：

- `news --server ... --category local --limit 1`：exit 0。
- `download --cut 00:00:20,00:00:30 --output custom.mp4 --push --push-target tg`：exit 0。
- `trim --duration 00:00:30 --output qa-cut.mp4`：exit 0。
- `push --text qa --target tg`：exit 0。
- `push-log --limit 1`：正確顯示 `downloaded` 時間。
- `--limit 0`、trim 缺少 end/duration、非法 ID：均 exit 2。

捕獲的請求 body：

```json
{"url":"https://www.tdm.com.mo/zh-hant/news-detail/1234567","overwrite":false,"push":true,"output":"custom.mp4","push_target":"tg","cut_start":"00:00:20","cut_duration":"00:00:30"}
{"file":"qa.mp4","start":"00:00:20","duration":"00:00:30","output":"qa-cut.mp4"}
{"text":"qa","target":"tg"}
```

### 受保護 Server 的 CLI 登入

- 未設定 `TDM_SERVER_PASSWORD`：exit 1。
- 密碼錯誤：exit 1。
- 設定正確 `TDM_SERVER_PASSWORD`：CLI 自動登入並成功查詢新聞，exit 0。

### 推送停用

- `PUSH_ENABLED=false tdm_tool.py push --text qa-no-send`：exit 1，未呼叫外部通道，無 traceback。
