## 1. 專案概覽

TDMDO 是一套以 **TDM 官方 API** 為核心的工具集，提供：

| 功能 | 說明 |
|---|---|
| 📰 新聞查詢 | 瀏覽最新新聞、關鍵字搜尋、僅影片過濾 |
| 🎬 影片下載 | 從 TDM URL / 新聞 ID 一鍵下載影片（m3u8 → mp4） |
| ✂️ 影片裁剪 | 精確到秒的無損 / 編碼裁剪 |
| ☁️ WebDAV 推送 | 下載完成後自動上傳到 Alist / OpenAlist |
| 🖥️ Web 網頁端 | Flask + 內嵌 HTML，圖形化操作 |
| 📊 本地資料庫 | SQLite 快取新聞全文 + 下載/推送記錄 |

**無需登入、無需 Cookie、無需瀏覽器 JS 渲染。**

## 3. 環境安裝

### 必要依賴

| 軟體 | 最低版本 | 安裝方式 |
|---|---|---|
| Python | ≥ 3.9 | [python.org](https://python.org) 或 `winget install python` |

## 4. 環境配置

### 4.1 建立 `.env`

```bash
cp .claude/skills/tdm/.env.example .claude/skills/tdm/.env
```

### 4.2 可配置變數

| 變數 | 預設值 | 說明 |
|---|---|---|
| `TDM_DOWNLOAD_DIR` | `<skill>/downloads` | 影片下載目錄 |
| `TDM_DB_PATH` | `<skill>/scripts/tdm_news.db` | SQLite 資料庫路徑 |
| `WEBDAV_ENABLED` | `false` | 是否啟用 WebDAV 自動推送 |
| `WEBDAV_URL` | 無 | WebDAV 伺服器 URL（含埠號） |
| `WEBDAV_USERNAME` | 無 | WebDAV 上傳帳號 |
| `WEBDAV_PASSWORD` | 無 | WebDAV 上傳密碼 |
| `WEBDAV_PATH` | `/` | WebDAV 上傳目標目錄 |

### 4.3 載入順序

```
系統環境變數 > .env 檔案 > 程式預設值
```

CLI 和 Web 啟動時自動載入 skill 目錄下的 `.env`，不依賴 python-dotenv。

## 5. CLI 命令

所有命令從專案根目錄執行。

### 5.1 查詢新聞

```bash
python .claude/skills/tdm/scripts/tdm_tool.py news [OPTIONS]
```

| 選項 | 說明 |
|---|---|
| `--limit N` | 顯示篇數（預設 10） |
| `--page N` | 頁碼（預設 1） |
| `--search KEYWORD` | 本地過濾關鍵字 |
| `--video-only` | 僅顯示有影片的新聞 |

**範例**：

```bash
# 最新 10 篇
python .claude/skills/tdm/scripts/tdm_tool.py news --limit 10

# 僅影片
python .claude/skills/tdm/scripts/tdm_tool.py news --video-only --limit 5
```

### 5.2 關鍵字搜尋

```bash
python .claude/skills/tdm/scripts/tdm_tool.py search KEYWORDS... [OPTIONS]
```

| 選項 | 說明 |
|---|---|
| `--limit N` | 顯示篇數（預設 20） |
| `--type {search_news,search_short_video,search_program}` | 搜尋類型 |
| `--video-only` | 僅含影片的新聞 |

**範例**：

```bash
# 搜尋「澳門 政府」
python .claude/skills/tdm/scripts/tdm_tool.py search 澳門 政府

# 搜尋節目 + 僅影片
python .claude/skills/tdm/scripts/tdm_tool.py search 風暴 --type search_program --video-only
```

### 5.3 下載影片

```bash
python .claude/skills/tdm/scripts/tdm_tool.py download --id ID | --url URL [OPTIONS]
```

| 選項 | 說明 |
|---|---|
| `--id ID` | 6-7 位 TDM 新聞 ID |
| `--url URL` | TDM 新聞/節目頁面 URL |
| `--output PATH` | 自訂輸出路徑 |
| `--cut START,DURATION` | 裁剪（如 `00:01:00,00:00:30`） |
| `--overwrite` | 強制覆蓋已存在的檔案 |

**範例**：

```bash
# 從 ID 下載
python .claude/skills/tdm/scripts/tdm_tool.py download --id 1217791

# 從 URL 下載
python .claude/skills/tdm/scripts/tdm_tool.py download --url "https://www.tdm.com.mo/zh-hant/news-detail/1217791?isvideo=true"

# 下載並裁剪 1:30 到 2:00
python .claude/skills/tdm/scripts/tdm_tool.py download --id 1217791 --cut "00:01:30,00:00:30"
```

**下載策略**：TDM m3u8 → yt-dlp（優先）→ ffmpeg（備援）

### 5.4 裁剪影片

```bash
python .claude/skills/tdm/scripts/tdm_tool.py trim --input FILE --start HH:MM:SS (--end HH:MM:SS | --duration HH:MM:SS) [--output PATH]
```

**範例**：

```bash
# 裁剪 20 秒到 50 秒
python .claude/skills/tdm/scripts/tdm_tool.py trim --input video.mp4 --start 00:00:20 --end 00:00:50

# 裁剪 20 秒起，持續 30 秒
python .claude/skills/tdm/scripts/tdm_tool.py trim --input video.mp4 --start 00:00:20 --duration 00:00:30
```

### 5.5 資料庫管理

```bash
python .claude/skills/tdm/scripts/tdm_tool.py db {init|stats|sync} [--force]
```

| 子命令 | 說明 |
|---|---|
| `init` | 初始化 / 重建資料庫表結構 |
| `stats` | 顯示統計（新聞數、影片數、推送數） |
| `sync` | 增量同步最新 40 篇新聞到 DB |
| `sync --force` | 強制更新既有新聞的完整 detail 資料 |

**範例**：

```bash
# 首次使用
python .claude/skills/tdm/scripts/tdm_tool.py db init
python .claude/skills/tdm/scripts/tdm_tool.py db sync --force

# 查看統計
python .claude/skills/tdm/scripts/tdm_tool.py db stats
```

### 5.6 查看推送記錄

```bash
python .claude/skills/tdm/scripts/tdm_tool.py push-log [--limit N]
```

## 6. Web 網頁端

### 6.1 啟動

```bash
# 僅本機
python app/tdm_web.py --host 127.0.0.1 --port 8080

# 內網可訪問（預設）
python app/tdm_web.py --port 8080
```

打開瀏覽器訪問 `http://127.0.0.1:8080` 或 `http://<本機IP>:8080`

### 6.2 功能頁籤

| 頁籤 | 功能 |
|---|---|
| 📰 新聞 | 瀏覽最新新聞、關鍵字搜尋、僅影片過濾、一鍵下載 |
| ⬇️ 下載 | 輸入 URL/ID → 查詢影片資訊 → 預覽 → 下載/裁剪 |
| 📁 已下載 | 已下載影片管理（播放、下載、裁剪、推送 WebDAV、刪除） |

### 6.3 已下載頁面功能

每個影片顯示：
- ☁️ **已推送** / **推送** 標記（從 DB 讀取狀態）
- 📥 下載 | 📋 複製連結 | ▶️ 播放 | ✂️ 裁剪 | 🔗 新聞頁 | 🗑 刪除

未推送的影片可以點「☁️ 推送」一鍵推送到 WebDAV。

### 6.4 內網訪問

預設綁定 `0.0.0.0`（所有介面），內網其他設備可直接訪問。

> ⚠️ Windows 防火牆需放行 8080 埠：
> `控制台 → 防火牆 → 進階設定 → 輸入規則 → 新增規則 → 連接埠 → TCP 8080 → 允許`

## 7. WebDAV 自動推送

### 7.1 原理

使用 **HTTP Basic Auth + WebDAV PUT**，相容 Alist / OpenAlist。無 JWT、無 Token 快取問題。

### 7.2 前置步驟

1. **Alist 後台** → 用戶 → 新增或編輯專用帳號
2. 勾選 **「WebDAV 讀寫」** 權限
3. 設定 `base_path` 限制用戶視野（可選，安全建議）
4. 確保目標目錄存在

### 7.3 配置 `.env`

```env
WEBDAV_ENABLED=true
WEBDAV_URL=http://10.10.10.149:5244
WEBDAV_USERNAME=tdm
WEBDAV_PASSWORD=your_password
WEBDAV_PATH=/TDM新聞/
```

### 7.4 行為

| 場景 | 行為 |
|---|---|
| CLI `download` | 下載完成 → 自動推送 → 寫 DB 記錄 |
| Web `download` | 同上 |
| Web 手動推送 | 點「☁️ 推送」按鈕 → 推送到 WebDAV |

推送失敗不影響下載結果。

## 8. 資料庫

### 8.1 結構

單表 `news`，14 個欄位：

| 欄位 | 類型 | 說明 |
|---|---|---|
| `id` | INTEGER PK | TDM 新聞 ID |
| `title` | TEXT | 標題 |
| `content` | TEXT | 新聞全文（HTML 已清除） |
| `date` | TEXT | 發布日期 |
| `video_url` | TEXT | m3u8 下載連結 |
| `share_url` | TEXT | 分享連結 |
| `raw_json` | TEXT | API 原始回應（完整 JSON） |
| `fetched` | TEXT | 最後擷取時間 |
| `created` | TEXT | TDM 創建時間 |
| `push_url` | TEXT | WebDAV 推送 URL |
| `push_time` | TEXT | 推送時間 |
| `download_method` | TEXT | `cli` 或 `web` |
| `download_dir` | TEXT | 下載目錄完整路徑 |

### 8.2 路徑

預設：`.claude/skills/tdm/scripts/tdm_news.db`

可透過 `TDM_DB_PATH` 環境變數自訂。

## 9. QClaw / 微信接入

### 9.1 部署方式

將整個 `.claude/skills/tdm/` 目錄複製到 QClaw 的工作區根目錄下。

### 9.2 前置條件

QClaw 所在電腦需要：

- Python ≥ 3.9
- ffmpeg（系統 PATH）
- `pip install requests`
- `.env` 配置（下載目錄、WebDAV 等）

### 9.3 使用

在微信中發送指令即可觸發 Claude Code 執行 TDM skill：

```
下載 TDM 新聞 1217791 的影片
搜尋最近澳門政府的新聞
查看下載記錄
```

### 9.4 網頁端

如需 Web UI，將 `app/tdm_web.py` 也複製過去，在 QClaw 電腦上啟動：

```bash
python app/tdm_web.py --port 8080
```

## 11. 疑難排解

### ffmpeg 找不到

```bash
# Windows
winget install ffmpeg
# 或手動下載 https://ffmpeg.org 加入 PATH

# 驗證
ffmpeg -version
```

### yt-dlp 下載失敗

部分網站可能需要瀏覽器 Cookie：

```bash
yt-dlp --cookies-from-browser chrome "URL"
```

或是用 `pip install yt-dlp` 升級到最新版。

### TDM API 無回應

TDM API 無需登入/Cookie。確認網路可訪問：

```bash
curl -s "https://www.tdm.com.mo/api/v1.0/news/1217791" -H "User-Agent: Mozilla/5.0"
```

### m3u8 過期

TDM 的 m3u8 token 有時效（通常數小時）。下載昨天的影片可能失敗，重新獲取最新資訊即可。

### WebDAV 推送 403

1. 確認 Alist 後台用戶勾選了 **「WebDAV 讀寫」** 權限
2. 確認 `.env` 中 `WEBDAV_USERNAME` / `WEBDAV_PASSWORD` 正確
3. 測試：`curl -u user:pass -T test.txt http://alist:5244/dav/test.txt`

### 內網無法訪問 Web 端

Windows 防火牆需放行 8080 埠。

### 資料庫損壞

```bash
# 重建
rm .claude/skills/tdm/scripts/tdm_news.db
python .claude/skills/tdm/scripts/tdm_tool.py db init
python .claude/skills/tdm/scripts/tdm_tool.py db sync --force
```
