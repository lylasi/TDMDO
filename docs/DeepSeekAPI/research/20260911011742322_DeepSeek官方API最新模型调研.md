## 结论

- 当前最新调用模型 ID：`deepseek-flash`（另有 `deepseek-v4-pro` 仍可调用，但计划下线）
- 最新发布的模型：**DeepSeek-V4.1-Flash**（发布日 2026-09-10），为全新模型结构系列中最小尺寸、原生多模态视觉理解模型

## 关键细节

- BASE URL（OpenAI 格式）：`https://api.deepseek.com`
- BASE URL（Anthropic 格式）：`https://api.deepseek.com/anthropic`
- 思考模式：默认开启，支持非思考/思考切换
- 功能支持：JSON Output、Tool Calls、Responses API、Anthropic API、对话前缀续写、FIM 补全（仅非思考模式）
- 并发限制：`deepseek-flash` 2500，`deepseek-v4-pro` 500
- 定价：`deepseek-flash` 空闲时段 输入(缓存命中) 0.02 元、输入(未命中) 1 元、输出 4 元 / 百万 tokens；高峰时段翻倍
- 高峰时段：北京时间周一至周五 9:00-12:00、14:00-18:00
